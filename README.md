# 🤖 Telegram Bot для публикации контента

Полнофункциональный бот для автоматической публикации контента в Telegram каналы и группы с топиками.

## ✨ Возможности

### 📝 Публикация контента
- ✅ Публикация в канал или группу (с выбором топика)
- ✅ Watermark на фото и видео
- ✅ Автоматическое форматирование постов
- ✅ Множественная загрузка медиа (альбомы)
- ✅ Поддержка хэштегов

### 📦 Пакетная загрузка
- ✅ Загрузка до 100 файлов одновременно
- ✅ Настройка расписания (минуты/часы/дни/недели)
- ✅ Выбор количества файлов в посте (1-10)
- ✅ Автоматическое разбиение на посты
- ✅ Перемешивание порядка постов

### 💾 Черновики
- ✅ Сохранение поста в черновик
- ✅ Просмотр списка черновиков
- ✅ Публикация из черновика
- ✅ Добавление черновика в очередь
- ✅ Удаление черновика

### 📥 Очередь публикаций
- ✅ Добавление постов в очередь
- ✅ Автоматическая публикация по расписанию
- ✅ Настройка интервала между постами
- ✅ Управление очередью (старт/стоп)
- ✅ Удаление отдельных постов из очереди
- ✅ Очистка всей очереди

### 🎨 Watermark
- ✅ Автоматическое добавление watermark на фото
- ✅ Автоматическое добавление watermark на видео
- ✅ Оптимизация для слабых серверов (Render.com)
- ✅ Настраиваемые параметры (размер, прозрачность, позиция)
- ✅ Fallback на оригинал при таймауте

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Создай файл `.env.txt`:
```
BOT_TOKEN=твой_токен_бота
ADMIN_IDS=твой_user_id
```

### 3. Настройка config.json

⚠️ **ВАЖНО!** Перед запуском проверь правильность thread_id для топиков группы.

#### Как узнать thread_id:

**Способ 1 — Автоматически (рекомендуется):**
```bash
python3 get_thread_ids.py
```

**Способ 2 — Вручную через Telegram Desktop:**
1. Открой группу
2. Кликни на топик
3. В URL будет: `...?thread=10`
4. Число после `thread=` — это thread_id

**Способ 3 — Через веб-версию:**
1. Открой группу в web.telegram.org
2. Кликни на топик
3. В URL будет: `...#-1003827311251_10`
4. Число после подчёркивания — это thread_id

#### Пример настройки категории:

Для **группы** (с топиками):
```json
"altushki": {
  "name": "Альтушки",
  "emoji": "🖤",
  "platform": "main_group",
  "topic": "altgirls",  ← НАЗВАНИЕ топика из platforms.topics
  "hashtags": [...]
}
```

Для **канала** (без топиков):
```json
"porno_channel": {
  "name": "Порно",
  "emoji": "🔥",
  "platform": "main_channel",  ← НЕ указываем "topic"!
  "hashtags": [...]
}
```

### 4. Запуск локально

```bash
python3 bot.py
```

### 5. Деплой на Render.com

1. Создай новый Web Service
2. Подключи GitHub репозиторий
3. В настройках:
   - **Build Command**: `bash render-build.sh`
   - **Start Command**: `python bot.py`
4. Добавь переменные окружения:
   - `BOT_TOKEN` = твой токен
   - `ADMIN_IDS` = твой user_id

FFmpeg установится автоматически через `render-build.sh`.

## 🎨 Настройка Watermark

В `config.json`:

```json
"watermark": {
  "enabled": true,
  "image_path": "watermark.png",
  "position": "bottom_right",
  "opacity": 0.8,
  "scale": 0.25,
  "scale_photo": 0.15,  // 15% ширины для фото
  "scale_video": 0.15,  // 15% ширины для видео
  "padding": 15
}
```

**Рекомендации для Render.com:**
- `scale_photo`: 0.10-0.20 (10-20%)
- `scale_video`: 0.10-0.20 (10-20%)
- `opacity`: 0.7-0.9 (70-90%)

Более крупный watermark → дольше обработка.

## 🔧 Решение проблем

### ❌ "не может найти тему"

**Причина**: Неправильный thread_id в config.json

**Решение**:
1. Запусти `python3 get_thread_ids.py`
2. Проверь все thread_id
3. Исправь в config.json

### ❌ Пост публикуется в "Главная" вместо нужной темы

**Причина**: В категории указан `"topic": "test"` (thread_id: 1)

**Решение**: Замени на правильный топик:
```json
"topic": "altgirls"  // вместо "test"
```

### ❌ Watermark не добавляется на видео на Render

**Причина**: Render.com имеет слабый CPU

**Решение**: Уже исправлено! Новый `media_processor.py`:
- ✅ Downscale до 720px (меньше пикселей)
- ✅ Preset `ultrafast` (быстрее)
- ✅ Таймаут 5 минут (больше времени)

В логах должно быть:
```
🎬 FFmpeg (Render): scale=0.15, opacity=0.80, preset=ultrafast, max_w=720px
✅ Видео watermark применен успешно
```

Если видео очень большое (>50MB):
```
❌ FFmpeg таймаут (>5 мин) - используем оригинал
```
Это нормально — бот опубликует оригинал БЕЗ watermark.

### ❌ Бот не запускается на Render

**Причина**: Не установлен ffmpeg

**Решение**: Проверь что в Render настроен `render-build.sh` как Build Command
